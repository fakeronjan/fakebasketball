Phase 2: Game work

  1. Replace real team names (active teams and defunct basketball teams) and remove "NBA standard" text
  2. Decide which interface ships: terminal version (touch UI can follow as a later update)
  3. Wrap it in Electron and set the cross-origin headers in the shell (desktop/)
  4. Bundle Pyodide inside the app so it runs fully offline
  5. Move saves to the user's AppData folder
  6. Desktop polish: window title, app icon, resizing/fullscreen, clean quit
  7. Set up a Windows test machine (free Windows 11 VM via UTM)
  8. Build the Windows version (cd desktop && npm run dist:win) and test it on that machine from scratch
  9. Upload the build to Steam with SteamPipe and set launch options
  10. Install through Steam on the test machine and play a full season
